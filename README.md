# SyncMeet

A Real-Time Communication Platform developed as an internship project.

## Overview

SyncMeet is a web-based collaboration platform that enables users to communicate and collaborate in real time. It provides meeting creation, video communication, screen sharing, file sharing, whiteboard collaboration, and user authentication.

## Features

* User Registration and Login using Firebase Authentication
* Instant Meeting Creation
* Join Meeting using Meeting Code
* Video Calling
* Screen Sharing
* Real-Time Whiteboard
* File Sharing
* Meeting Chat
* Responsive and Modern User Interface

## Technologies Used

## Installation

1. Clone the repository

git clone https://github.com/dishadeepak10/syncmeet.git

2. Install dependencies

npm install

3. Run the server

node server.js

4. Open the application

http://localhost:3000
